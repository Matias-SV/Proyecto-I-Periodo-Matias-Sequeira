### Descripción del Proyecto ###
Sistema de Gestión de Contactos desarrollado en Python y el microframework Flask para la subárea de Programación Web. La aplicación permite realizar de forma dinámica la autenticación de usuarios, el control, edición, búsqueda y generación de reportes avanzados de contactos, empleando una arquitectura limpia y persistencia de datos estructurada mediante una hoja de cálculo en formato Excel (contactos.xlsx).

### Estructura de Archivos del Repositorio ###
app.py: Código fuente principal y lógica del servidor Flask.

contactos.xlsx: Base de datos local para el almacenamiento persistente de los registros.

README.txt / README.md: Documentación e información base del sistema.

static/: Recursos estáticos independientes (subcarpetas css/ para los estilos visuales de los formularios, login y perfiles; e Images/ para los elementos gráficos de la interfaz).

templates/: Vistas y plantillas HTML dinámicas del sistema de gestión.
